1. Proyecto / Contexto

¿Qué es CatLin Studio?

Un estudio de belleza y bienestar que ofrece servicios profesionales de manicura, diseño de cejas, extensiones de pestañas y masajes relajantes. El sitio web fue transformado de una página estática a una aplicación web interactiva que simula el proceso completo de reserva de turnos.

Circuito de negocio simulado

  1. Explorar — El usuario navega el catálogo de servicios con filtros por categoría
  2. Seleccionar — Agrega servicios a su reserva con un clic
  3. Personalizar — Elige fecha y horario disponible
  4. Registrarse — Completa sus datos personales (nombre, email, teléfono)
  5. Confirmar — Revisa el resumen y confirma la reserva
  6. Recibir — Obtiene un número de reserva único como comprobante

Tecnologías aplicadas

HTML5 semántico CSS3 / SASS (7-1) Bootstrap 5 JavaScript (ES6+) SweetAlert2 AOS JSON + Fetch Git / GitHub Vercel

Fetch de datos JSON

function fetchJSON(url) {
    return fetch(url).then(response => {
        if (!response.ok) throw new Error('Error al cargar datos');
        return response.json();
    });
}

// Uso en servicios
if (servicesContainer) {
    fetchJSON('data/services.json')
        .then(services => renderServices(services, servicesContainer, false))
        .catch(() => { /* manejo de error visual */ });
}

Renderizado dinámico con DOM

function buildServiceCard(service, showAddButton = false) {
    const col = document.createElement('div');
    col.className = 'col-md-6 col-lg-4';
    col.innerHTML = `
        <div class="service-card h-100">
            <img src="${service.image}" alt="${service.name}" loading="lazy">
            <div class="card-body">
                <h3>${service.name}</h3>
                <p>${service.description}</p>
                <span class="badge">$${service.price}</span>
                ${showAddButton ? `<button class="btn-add-service">Agregar</button>` : ''}
            </div>
        </div>`;
    return col;
}

8. Reflexión Final

El desarrollo de CatLin Studio como aplicación web interactiva permitió integrar y aplicar la totalidad de los conceptos aprendidos durante el curso de JavaScript y desarrollo frontend. A continuación se detalla cómo cada concepto teórico se tradujo en una implementación concreta:

Variables y tipos de datos

Se utilizó const y let de forma consistente: const para referencias del DOM, configuraciones y funciones; let para el estado mutable de la reserva (`bookingState`). Se trabajó con objetos, arrays primitivos y anidados.

Funciones y ámbito

Se definieron funciones con nombre descriptivo (`fetchJSON`, `buildServiceCard`, `renderServices`, `updateBookingSummary`) que encapsulan lógica específica. El cierre (closure) se usó implícitamente en los callbacks de eventos y promesas, manteniendo acceso al estado del módulo.

Manipulación del DOM

Se crearon elementos dinámicamente con document.createElement y innerHTML, se modificaron clases con classList, se manejó el scroll con scrollIntoView y se aplicó delegación de eventos en contenedores para manejar clics en botones agregados dinámicamente.

Asincronismo (Fetch + Promesas)

Los datos de servicios y testimonios se cargan desde archivos .json mediante fetch(), usando promesas (.then/.catch) para procesar la respuesta sin bloquear la interfaz. Los errores de red se manejan con fallbacks visuales amigables.

Métodos funcionales de arrays

Se utilizaron filter() para filtrar servicios por categoría, find() para buscar un servicio por ID, map() para transformar datos en la interfaz y reduce() para calcular el total de la reserva. Estos métodos reemplazan bucles tradicionales y hacen el código más declarativo.

Librerías externas

SweetAlert2 se integró para reemplazar los cuadros de diálogo nativos (alert/confirm/prompt), proporcionando modales visualmente consistentes con la identidad de CatLin Studio. AOS se mantuvo como librería de animaciones. Bootstrap 5 se utilizó como framework CSS.

Buenas prácticas

  • Sin código comentado ni en desuso
  • Nombres descriptivos en funciones y variables
  • Sin console.log, alert, confirm ni prompt
  • Manejo de errores con try/catch implícito en promesas
  • Código estructurado en módulos lógicos (fetch, render, eventos, booking)

Dificultades encontradas

La principal dificultad fue migrar de un sitio estático a uno interactivo sin romper la funcionalidad existente. El uso de @use en SASS requirió ajustar las rutas relativas correctamente. La delegación de eventos en elementos generados dinámicamente también presentó un desafío inicial que se resolvió usando e.target.closest().

Conclusión

El simulador de reservas de CatLin Studio demuestra la aplicación práctica de todos los conceptos del curso: desde la sintaxis básica de JavaScript hasta el asincronismo, pasando por la manipulación del DOM y la integración de librerías externas. El resultado es una aplicación web funcional, responsive, con código limpio y mantenible, lista para ser presentada como proyecto final.
