1. Proyecto / Contexto

¿Qué es CatLin Studio?

Estudio de belleza y bienestar con servicios de manicura, diseño de cejas, extensiones de pestañas y masajes relajantes. El sitio fue transformado de una página estática a una aplicación web interactiva que simula el proceso completo de reserva de turnos.

Circuito de negocio simulado

  1. Explorar — Catálogo de servicios con filtros por categoría
  2. Seleccionar — Agregar servicios a la reserva con un clic
  3. Personalizar — Elegir fecha y horario disponible
  4. Registrarse — Completar datos personales (nombre, email, teléfono)
  5. Confirmar — Revisar resumen y confirmar la reserva
  6. Recibir — Obtener un número de reserva único como comprobante

Tecnologías aplicadas

HTML5 semántico CSS3 / SASS (7-1) Bootstrap 5 JavaScript (ES6+) SweetAlert2 AOS JSON + Fetch Git / GitHub Vercel

4. Código — JavaScript

📌 Abrir assets/js/main.js en VS Code. Capturar las secciones de fetch, render, eventos y booking.

Fetch de datos JSON

function fetchJSON(url) {
    return fetch(url).then(response => {
        if (!response.ok) throw new Error('Error al cargar datos');
        return response.json();
    });
}

// Uso: cargar servicios
fetchJSON('data/services.json')
    .then(services => renderServices(services, container, true))
    .catch(() => { /* fallback visual */ });

Renderizado dinámico con el DOM

function buildServiceCard(service, showAddButton) {
    const col = document.createElement('div');
    col.className = 'col-md-6 col-lg-4';
    col.innerHTML = `
        <div class="service-card h-100">
            <img src="${service.image}" alt="${service.name}" loading="lazy">
            <div class="card-body">
                <h3>${service.name}</h3>
                <p>${service.description}</p>
                <span class="badge">$${service.price}</span>
                ${showAddButton ? '<button>Agregar</button>' : ''}
            </div>
        </div>`;
    return col;
}

8. Reflexión Final

El desarrollo de CatLin Studio como aplicación web interactiva permitió integrar y aplicar todos los conceptos aprendidos durante el curso de JavaScript y desarrollo frontend. Cada concepto teórico se tradujo en una implementación concreta dentro del proyecto.

Variables y tipos de datos

Se utilizó const para referencias del DOM, configuraciones y funciones. let para el estado mutable de la reserva. Se trabajó con objetos, arrays de objetos y tipos primitivos de forma consistente.

Funciones y ámbito

Funciones con nombre descriptivo encapsulan lógica específica: fetchJSON(), buildServiceCard(), renderServices(), updateBookingSummary(). Los closures aparecen naturalmente en callbacks de eventos y promesas.

Manipulación del DOM

Creación dinámica de elementos con createElement e innerHTML. Modificación de clases con classList. Scroll suave con scrollIntoView. Delegación de eventos en contenedores padres para manejar clics en botones agregados dinámicamente.

Asincronismo (Fetch + Promesas)

Los datos de servicios y testimonios se cargan desde archivos .json mediante fetch() con promesas. El manejo de errores con .catch() muestra fallbacks visuales sin romper la experiencia.

Métodos funcionales de arrays

filter() para filtrar por categoría, find() para buscar por ID, map() para transformar datos en la interfaz, reduce() para calcular totales. Reemplazan bucles tradicionales con código declarativo.

Librerías externas

SweetAlert2 reemplazó alert/confirm/prompt con modales visuales consistentes con la paleta de colores del estudio. AOS aporta animaciones de scroll. Bootstrap 5 proporciona el sistema de grillas y componentes base.

Buenas prácticas

  • Cero código comentado o en desuso
  • Nombres descriptivos de funciones y variables
  • Sin console.log, alert, confirm ni prompt
  • Manejo de errores con fallbacks visuales
  • Código estructurado en secciones lógicas dentro de un único archivo JS

Dificultades encontradas

Migrar de un sitio estático a interactivo sin romper funcionalidad existente. Ajustar rutas relativas en SASS con @use. Delegación de eventos en elementos generados dinámicamente, resuelto con e.target.closest().

Conclusión

CatLin Studio demuestra la aplicación práctica de todos los conceptos del curso: desde sintaxis básica hasta asincronismo, manipulación del DOM e integración de librerías. El resultado es una aplicación web funcional, responsive, con código limpio y mantenible.
